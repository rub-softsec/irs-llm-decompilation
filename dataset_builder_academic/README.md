# Dataset Builder (Academic)

This directory contains the computational framework for processing, analyzing, and selecting C code samples for the dataset construction, with a specific focus on Halstead complexity metrics. The pipeline ensures a balanced distribution of code complexity across the dataset, which is critical for the validity of the subsequent experimental analysis.

## Components

*   **calculator_halstead.py**: Script for calculating Halstead complexity metrics (Volume, Difficulty, Effort) for each function in the dataset. This quantitative analysis provides the basis for the sampling strategy.
*   **select.py**: Algorithm for stratified sampling. It selects a representative subset of function samples across defined difficulty buckets (1.0 - 75.0) to minimize bias and ensure diverse complexity representation.

---

## Usage

To replicate the dataset construction process, the scripts must be executed in the sequential order described below.

### 1. Data Setup

The scripts assume the existence of an `input` directory containing the raw dataset files from ExeBench.

**Required Directory Hierarchy:**

```text
[dataset_builder_academic]
├── real_test.jsonl         <-- Original raw dataset (Input for Step 1)
├── real_test_scored.jsonl  <-- Generated by Step 1 (Input for Step 2)
├── output/                 <-- Automatically created by Step 2
│   ├── selected.jsonl      <-- Final balanced dataset
```

### 2. Execution Workflow

#### Step 1: Metric Calculation

Execute `calculator_halstead.py` to process the raw JSONL dataset and append complexity metrics to each entry.

```bash
python3 calculator_halstead.py
```
*   **Function**: Initializes the `HalsteadMetricsCalculator` class to parse C function definitions and compute Halstead metrics.
*   **Input**: `real_test.jsonl` (default configuration).
*   **Output**: `real_test_scored.jsonl`, an annotated JSONL file with a `halstead` field containing `volume`, `difficulty`, and `effort`.

#### Step 2: Stratified Sampling

Execute `select.py` to generate the final balanced dataset.

```bash
python3 select.py
```
*   **Function**: Initializes the `DatasetSelector` class to filter samples based on difficulty and perform stratified sampling to ensure uniform distribution across difficulty buckets.
*   **Input**: `real_test_scored.jsonl` (expected in the script's directory or configured input path).
*   **Output**: `output/selected.jsonl`, containing the curated subset of functions.

### 3. Generated Outputs

The process generates an `output/` directory containing the final artifact:

*   **selected.jsonl**: The selected dataset, ready for availability in the experimental pipeline. It guarantees a statistically balanced representation of code complexity.

### 4. Selected Dataset Subset

The repository includes a selected subset of the ExeBench test split, stored in the `exebench_test_subset` directory.

*   **exebench_test_subset.json**: A JSON file containing a list of functions, each representing a selected function with its original path and definition.
